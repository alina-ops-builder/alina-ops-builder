## How I work

- **Start from the process, not the tool.** Map what happens today, then decide whether AI helps at all.
- **Measure outcomes, not activity.** Cycle time, capacity and cost, not hours saved on paper.
- **Ship with guardrails.** Human review where errors are costly, security review for new tools, and logs you can audit.
